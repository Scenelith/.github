## Build with Scenelith

- **[Scenelith Self-Hosted](https://github.com/Scenelith/scenelith-selfhost)** — inspectable source-available distribution with Docker, PostgreSQL, Redis, local or S3-compatible media storage, and no Cloud billing dependency.
- **[Releases](https://github.com/Scenelith/scenelith-selfhost/releases)** — signed, versioned multi-architecture container images with SBOM and provenance.
- **[Discussions](https://github.com/Scenelith/scenelith-selfhost/discussions)** — setup help, workflows, provider questions, and community ideas.
- **[Issues](https://github.com/Scenelith/scenelith-selfhost/issues/new/choose)** — reproducible defects and focused feature requests.

Self-hosted operators keep projects, media, database, storage, and provider credentials on infrastructure they control. Provider credentials are sent only to the provider they authenticate against, never to Scenelith Cloud.
