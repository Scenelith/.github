## Build with Scenelith

- **[Scenelith](https://github.com/Scenelith/scenelith)** — the canonical source-available product and complete self-hosted distribution.
- **[Releases](https://github.com/Scenelith/scenelith/releases)** — signed, versioned multi-architecture images and verified installation bundles.
- **[Discussions](https://github.com/Scenelith/scenelith/discussions)** — setup help, workflows, provider questions, and community ideas.
- **[Issues](https://github.com/Scenelith/scenelith/issues/new/choose)** — reproducible defects and focused feature requests.

Self-hosted operators keep projects, media, database, storage, and provider credentials on infrastructure they control. Provider credentials are sent only to the provider they authenticate against, never to Scenelith Cloud.
